# Photos Library Cleaner

A native macOS/iOS application that automates the cleanup and organization of the Apple Photos library.

## Overview

Photos Library Cleaner helps you manage your photo library by:

- Deleting blurry photos
- Deleting low-quality/bad photos and videos
- Removing redundant and duplicate media
- Coalescing similar shots into one or two best selections
- Identifying and removing temporary task-related photos/videos
- Organizing the remaining photos into events with appropriate labels and dates

## Features

- **PhotoKit Integration**: Secure access to your photo library
- **ML Analysis**: On-device machine learning for photo quality assessment
- **User-Friendly Interface**: Intuitive UI for reviewing and managing photos
- **Non-Destructive Deletions**: All deletions use the Photos "Recently Deleted" feature

## Requirements

- iOS 15.0+ / macOS 12.0+
- Xcode 14.0+
- Swift 5.0+

## Installation

1. Clone the repository
2. Open the Xcode project
3. Build and run on your device or simulator

## Privacy

- All photo analysis is performed on-device
- No photos are uploaded to external servers
- The app requires photo library access permission
